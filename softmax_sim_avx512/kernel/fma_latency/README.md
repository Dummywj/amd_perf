# FMA Latency

- **语义**：维护 16 个逻辑 lane 的状态。每个 16 元素块先执行
  `state[lane] += input[index + lane]`，随后对状态连续执行 16 次
  `state = state * 1.0001 + 0.0003`，并保存当前状态。
- **输入布局**：`input[0:N]`，一个连续 FP32 向量。
- **资源覆盖**：同一个向量状态贯穿全部循环迭代，下一块的 add 和 FMA 都依赖上一块
  最后一条 FMA，防止乱序执行跨迭代隐藏 latency。
- **跨 ISA 约束**：x86 固定为 16 个 ZMM lane；RVV 使用 `e32m4` 和固定 AVL=16，
  因而在 VLEN=128/512 下保持相同的逻辑 lane 和输出语义。
- **输出**：`output[0:N]` 保存各块执行后的累计状态；`N` 必须是 16 的倍数。
